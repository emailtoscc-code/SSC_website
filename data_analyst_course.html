📚 Module-wise Syllabus

Click a module to expand the detailed topics.

01. Data Analytics Fundamentals
  • What is Data Analytics?
  • Data Analyst vs Data Scientist vs Data Engineer
  • Descriptive, Diagnostic, Predictive & Prescriptive Analytics
  • Data types, datasets, KPIs and metrics
  • Business questions and requirements
  • Analytics workflow: Collect → Clean → Analyze → Visualize → Communicate
02. Advanced Microsoft Excel
  • Excel Tables, sorting, filtering and validation
  • SUM, AVERAGE, COUNT, IF, AND, OR, IFERROR
  • SUMIF/SUMIFS, COUNTIF/COUNTIFS, AVERAGEIFS
  • VLOOKUP, XLOOKUP, INDEX-MATCH, XMATCH
  • Text & Date functions
  • Data cleaning, duplicates and missing values
  • Pivot Tables, Pivot Charts and Slicers
  • Power Query and Power Pivot
  • Interactive Excel dashboards
03. SQL for Data Analysis
  • Database, tables, keys and relationships
  • SELECT, WHERE, DISTINCT, ORDER BY
  • LIKE, IN, BETWEEN and NULL handling
  • COUNT, SUM, AVG, MIN, MAX
  • GROUP BY, HAVING and CASE WHEN
  • INNER, LEFT, RIGHT, FULL, SELF and CROSS JOIN
  • UNION and UNION ALL
  • Subqueries and Views
  • CTEs and Window Functions
  • ROW_NUMBER, RANK, DENSE_RANK, LAG, LEAD
04. Statistics for Data Analysis
  • Mean, Median, Mode and Range
  • Variance and Standard Deviation
  • Percentiles, Quartiles and IQR
  • Outlier detection
  • Probability and Sampling
  • Correlation vs Causation
  • Confidence Intervals
  • Hypothesis Testing and P-value
  • T-Test, Chi-Square and ANOVA
  • Regression basics
05. Python for Data Analysis
  • Python fundamentals, conditions, loops and functions
  • Lists, Tuples, Sets and Dictionaries
  • NumPy arrays and operations
  • Pandas Series and DataFrames
  • CSV/Excel import and data inspection
  • Filtering, sorting and missing values
  • GroupBy, Merge, Join, Concat and Pivot
  • Matplotlib and Seaborn
  • Exploratory Data Analysis (EDA)
06. Power BI & DAX
  • Power BI Desktop and data sources
  • Power Query cleaning and transformation
  • Merge and Append queries
  • Data modeling, relationships and Star Schema
  • Fact & Dimension tables
  • DAX calculated columns and measures
  • CALCULATE, FILTER, SUMX, COUNTX
  • MTD, YTD and previous-year analysis
  • KPI cards, charts, slicers and drill-through
  • Bookmarks, tooltips, publishing and sharing
07. AI for Data Analysts 🤖
  • Generative AI fundamentals
  • Prompt Engineering for analytics
  • AI for Excel formulas, SQL and Python
  • AI-assisted data cleaning and insights
  • AI-assisted reports and documentation
  • Verify AI output and avoid hallucinations
  • Data privacy and responsible AI
08. Business Intelligence & Data Storytelling
  • Business requirements and KPI selection
  • Choosing the right chart
  • Dashboard design principles
  • Finding trends, patterns and anomalies
  • Actionable recommendations
  • Presenting insights to management
