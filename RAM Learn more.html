3.1 · Purpose

A temporary desk
for running programs

Every app, game, browser tab or file you open is loaded into RAM so the processor can work on it instantly. Close everything, and RAM is cleared for the next job.

Running apps live here Cleared on restart
A

The Study-Desk Analogy

Easy way to remember

Cupboard = Storage

SSD / HDD keeps all your books (files) permanently.

Desk = RAM

You open books on the desk to actually study (run programs).

Bigger Desk = More RAM

More books open at once → smoother, faster multitasking.

When you sleep (switch off the PC), everything left on the desk is cleared away — that is why RAM is temporary.

Feeds the Processor

The CPU reads instructions and data directly from RAM, thousands of times faster than from a drive.

Random Access

Any memory cell can be reached equally fast — no need to read in order like a cassette tape.

3.3 · Types

Three generations:
DDR3, DDR4, DDR5

DDR = Double Data Rate — each generation transfers more data per second while using less power.

GEN 2007 LEGACY · OLDER PCs

DDR3

Speed800 – 2133 MT/s
Voltage1.5 V
Common size2 – 8 GB
Found inOld laptops & PCs
GEN 2014 MOST COMMON

DDR4

Speed2133 – 3200+ MT/s
Voltage1.2 V

GEN 2020 LATEST & FASTEST

DDR5

Speed4800 – 8400+ MT/s
Voltage1.1 V
Common size16 – 64 GB
Found inNew gaming & pro PCs

Remember: these are not interchangeable! A DDR4 stick will not fit in a DDR5 slot — the notch position is different. Always check your motherboard before buying RAM.

    3.5 · The Golden Rule

    Power off = data gone

    RAM is volatile memory. It only holds data while electricity flows. Try it yourself — this grid is your RAM, filled with live data:

    SYSTEM STATUS: POWER ON RAM UPTIME: 00:00

    40/40 DATA BLOCKS ACTIVE

    RAM USAGE

    64%

    Go on — flip the switch and watch the data vanish instantly.

    Real-life effect: unsaved work (a Word file, a painting) disappears if the PC suddenly shuts down. Always press Save!

    Also why restarting helps: a restart empties RAM completely, clearing stuck programs and making the PC feel fresh.
