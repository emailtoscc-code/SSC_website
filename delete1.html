What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language for creating web pages.

What is HTML Used For?

HTML is used to:

  • Create the structure of web pages
  • Display text, images, and multimedia
  • Create forms and input fields
  • Create links between pages
EXAMPLE
<!DOCTYPE html> <html> <head> <title>My First Page</title> </head> <body> <h1>Hello World!</h1> <p>This is my first web page.</p> </body> </html>

HTML Elements

An HTML element is defined by a start tag, some content, and an end tag.

HTML Element Structure

<tagname>Content goes here...</tagname>

Examples of Common Elements

EXAMPLE
<h1>This is a heading</h1> <p>This is a paragraph.</p> <a href="https://google.com">This is a link</a> <img src="image.jpg" alt="Description">

HTML Attributes

HTML attributes provide additional information about HTML elements.

Attribute Structure

<tag attribute="value">Content</tag>

Common Attributes

  • href - Specifies the URL for links
  • src - Specifies the source of an image
  • alt - Alternative text for images
  • style - Inline CSS styles
  • class - CSS class name
  • id - Unique identifier
EXAMPLE
<a href="https://google.com">Visit Google</a> <img src="photo.jpg" alt="My Photo" width="300"> <p style="color: red;">Red Text</p> <div id="main">Main Content</div>

HTML Headings

HTML headings are used to define headings on a page. There are 6 levels: h1 to h6.

Heading Importance

  • <h1> - Most important (main title)
  • <h2> - Less important
  • <h3> to <h6> - Progressively less important
EXAMPLE
<h1>Main Heading</h1> <h2>Subheading</h2> <h3>Sub-subheading</h3>

HTML Paragraphs

The <p> tag defines a paragraph. Browsers automatically add space before and after a paragraph.

EXAMPLE
<p>This is a paragraph.</p> <p>This is another paragraph.</p>

Formatting Text Within Paragraphs

  • <strong> - Bold text with strong importance
  • <em> - Italic text with emphasis
  • <br> - Line break
  • <hr> - Horizontal rule

What is CSS?

CSS stands for Cascading Style Sheets. It is used to style and layout web pages.

Three Ways to Write CSS

  • Inline CSS - Style attribute on HTML elements
  • Internal CSS - Style tag in the head section
  • External CSS - Separate CSS file linked to HTML
EXAMPLE
<style> h1 { color: red; font-size: 32px; } p { color: blue; } </style>

What is JavaScript?

JavaScript is a programming language that makes web pages interactive. It can change HTML content, styles, and respond to user actions.

EXAMPLE
<script> document.getElementById("demo").innerHTML = "Hello JavaScript!"; </script>
