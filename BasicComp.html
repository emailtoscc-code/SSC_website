What is a Computer?



A computer is an electronic device that processes data

A computer is an electronic device that processes data and performs calculations at high speed. It accepts input, processes it according to instructions, and produces output.

Key Characteristics of Computers

  • Speed: Computers process information extremely fast (millions of operations per second)
  • Accuracy: Computers perform calculations with high precision
  • Reliability: Computers consistently perform tasks without errors
  • Versatility: Computers can perform many different types of tasks
  • Automation: Computers can work continuously without human intervention

How Computers Work (Basic Process)

Core Computer Cycle

01
INPUT

User enters data (keyboard, mouse, etc.)

02
PROCESSING

Computer processes data using the CPU

03
OUTPUT

Results are displayed (monitor, printer, etc.)

04
STORAGE

Data is saved for future use

Uses of Computers in Daily Life

  • Communication (Email, Video Calls, Social Media)
  • Entertainment (Games, Movies, Music Streaming)
  • Work & Business (Documents, Spreadsheets, Presentations)
  • Education (Online Learning, Research)
  • Shopping & Banking (E-commerce, Online Banking)
  • Healthcare (Medical Records, Online Consultation)
💡 Tip: Every electronic device that performs computation is a computer – from your smartphone to smartwatches.

History and Types of Computers

Evolution of computers through different generations

Brief History of Computers

  • 1940s-1950s: First Generation - Large, room-sized computers using vacuum tubes
  • 1960s: Second Generation - Transistors replaced vacuum tubes, smaller size
  • 1970s: Third Generation - Introduction of microprocessors and personal computers
  • 1980s: Fourth Generation - Personal computers became popular (IBM PC, Apple)
  • 1990s-Present: Fifth Generation - Internet, mobile devices, cloud computing

Types of Computers

1. Personal Computers (Desktop)

CHARACTERISTICS
• Stationary desktop setup • Separate monitor, keyboard, mouse • Most powerful for home/office work • Examples: Dell, HP, Lenovo desktops

2. Laptop/Notebook Computers

  • Portable and lightweight
  • Built-in keyboard, trackpad, and screen
  • Battery-powered for portability

3. Tablets

  • Touch-screen devices larger than smartphones
  • Used for browsing, reading, light work
  • Examples: iPad, Samsung Tab

4. Smartphones

  • Handheld mobile computers
  • Built-in camera, GPS, sensors
  • Used for communication, entertainment, productivity

5. Servers & Mainframes

  • Powerful computers used by organizations
  • Handle large amounts of data and multiple users
  • Used in banks, hospitals, large companies

Basic Computer Terminology

Understanding basic computer terminology

Essential Computer Terms

1. Hardware

Definition: The physical components of a computer that you can touch.

  • Examples: Monitor, Keyboard, Mouse, CPU, RAM, Hard Drive
  • Can wear out over time and may need replacement

2. Software

Definition: Programs and applications that run on a computer.

  • Examples: Windows, Microsoft Word, Google Chrome, Games
  • Intangible - not physical but exists as code

3. Data

Definition: Information that computers process and store.

  • Can be text, numbers, images, videos, or audio
  • Raw input that needs to be processed

4. Operating System (OS)

Definition: The main software that controls the computer and all its programs.

  • Examples: Windows, macOS, Linux, iOS, Android
  • Manages hardware resources and controls program execution

5. Peripherals

Definition: External devices connected to the computer.

  • Examples: Printers, Speakers, External Hard Drives, Scanners

File and Folder Management

Organizing files and folders on your computer

Understanding Files and Folders

What is a File?

  • A collection of data stored on your computer
  • Has a name and file extension (.txt, .jpg, .docx)
  • Examples: Documents, Photos, Videos, Programs

What is a Folder?

  • Container for organizing files
  • Can contain other folders (subfolders)
  • Creates a hierarchical structure

File Operations

Creating a New Folder

HOW TO CREATE A FOLDER
Method 1: Right-click in File Explorer → Select "New" → "Folder" → Type folder name → Press Enter Method 2: Using keyboard shortcut → Press Ctrl + Shift + N (in File Explorer) → Type folder name → Press Enter

Naming Files and Folders

ℹ️ Naming Rules: Cannot use: < > : " / \ | ? * at the end. Use clear, descriptive names. Example: "Project_Report_2024" instead of "File1"

Moving and Copying Files

  • Copy: Right-click → Copy (or Ctrl+C) → Right-click → Paste (Ctrl+V)
  • Move: Right-click → Cut (or Ctrl+X) → Right-click → Paste (Ctrl+V)
  • Drag & Drop: Click and drag file to new location

Deleting Files and Folders

  • Right-click → Delete (or press Delete key)
  • Files go to Recycle Bin (recovery possible)
  • To permanently delete: Shift+Delete
  • Empty Recycle Bin to free space

Organizing Your Files

💡 Best Practices: Create a logical folder structure. Example: My Documents → Projects → Project_2024 → Reports. Regularly delete unnecessary files. Use cloud storage for backups.

Internet and World Wide Web Basics

Understanding the internet and how it works

What is the Internet?

The Internet is a global network of computers and servers connected together, allowing information to be shared worldwide.

Key Internet Concepts

IP Address

  • Unique identification number for each device on internet
  • Format: 192.168.1.1 (IPv4) or newer (IPv6)
  • Like a postal address for computers

Domain Names and URLs

URL STRUCTURE
https://www.google.com https:// = Protocol (secure connection) www = World Wide Web prefix google = Domain name .com = Top-Level Domain (TLD) Other TLDs: .org = Organization .edu = Educational .gov = Government .net = Network

Internet Connection Types

Home Internet Options

  • Broadband (Cable): Fast, reliable, most common
  • Fiber Optic: Extremely fast, newest technology
  • DSL: Older technology over phone lines
  • Satellite: For remote areas, slower
  • Mobile/5G: Using cellular network

How the Internet Works

💡 Simplified Process: You send a request (typing URL) → Request goes to server → Server sends data back → Browser displays webpage. All happens in milliseconds!

Internet Safety and Security

Protecting yourself from online threats and malware

Common Internet Threats

Malware

  • Malicious software designed to harm your computer
  • Viruses, Worms, Trojans, Spyware, Adware
  • Can steal data or damage system

Phishing

  • Fraudulent emails pretending to be legitimate
  • Try to steal your passwords or financial info
  • Never click links in suspicious emails

Ransomware

  • Encrypts your files and demands payment
  • Don't pay ransom - contact authorities
  • Keep backups to protect against this

Data Backup & Recovery Masterclass

Data Backup & Recovery

Complete information and best strategies to protect your important data, personal files and documents from permanent loss.

💾 What is Data Backup & Recovery ?

Data backup means keeping an additional copy of important files (such as photos, videos, documents) on your computer, laptop, or phone somewhere safe. If the system ever crashes, the laptop gets stolen, or it gets attacked by a virus, we can easily recover that data.

Without a backup, data loss can be difficult or extremely expensive to recover. Therefore, following the principle of "prevention is better than cure," regular backups are essential.

⚙️ Types of Backups

You can choose from any of these 3 main backup methods depending on your needs:

1. Full Backup

It backs up all your computer's data (OS, software, and files) at once. It's the most secure, but it takes more time and storage.

2. Incremental Backup

It only backs up data that has been newly created or modified since the last backup. It's fast and saves storage.

3. Cloud Backup

Data is automatically saved via the internet to cloud platforms like Google Drive, OneDrive, or Dropbox. This allows you to access it anytime, anywhere.

🛡️ The Famous 3-2-1 Backup Rule

Industry experts consider the '3-2-1 Rule' to be the best rule for data security:

What does this rule say ?

  • 3 Copies: Make a total of 3 copies of your data (1 main data + 2 backup copies).
  • 2 Different Media: Save data on 2 different storage types (like 1 Internal Drive and 1 External Hard Drive).
  • 1 Offsite Location: Keep at least 1 backup copy somewhere else or on cloud storage so that the data remains safe even in case of a fire or theft at home.

🔄 Disaster Recovery Process

If for some reason your data has been deleted or the system has crashed, then the data can be recovered by following these steps:

1. Stop Using the Drive:If the data is deleted, avoid writing anything else on that drive so that the old data is not overwritten

2. Use Trusted Recovery Software: Use reliable data recovery tools like Recuva, EaseUS, or Disk Drill.

3. Restore from Backup: If you have already taken a backup on Cloud or External Drive, then restore it immediately.

⭐ Best Practices for Data Safety

Some important things that you should always keep in mind:

  • Automated Backups: Schedule backup of your important folders so that it happens automatically in the background.
  • Regular Testing: Just taking a backup is not enough, restore it from time to time and check whether the file is working properly or not.
  • Antivirus Protection: Always use an updated antivirus to protect yourself from ransomware and malware.

❓ Frequently Asked Questions

Q: Can mobile data also be backed up on the cloud ?

A: Yes, you can back up contacts, photos, and settings using Google Drive for Android and iCloud for iPhone.

Q: How long does an external hard drive last ?

A: Generally a good external hard drive lasts for 3 to 5 years, so it is better to replace it from time to time or make a new backup.
