Introduction to Microsoft Excel Interface

Microsoft Excel is a powerful spreadsheet program that allows you to organize, analyze, and visualize data. It consists of workbooks containing multiple worksheets.

Excel Interface Components

  • Ribbon - Contains tabs with commands and tools
  • Worksheet - The grid where you enter data (columns A-Z, AA-AZ, etc., rows 1-1,048,576)
  • Formula Bar - Shows the contents of the active cell
  • Name Box - Shows the address of the active cell
  • Status Bar - Shows summary information and view options

Creating and Managing Workbooks

WORKBOOK OPERATIONS
Creating a new workbook: - File → New → Blank Workbook - Ctrl + N (keyboard shortcut) Saving workbooks: - File → Save As - Ctrl + S (Save) - F12 (Save As) Managing worksheets: - Insert → Insert Sheet - Right-click sheet tab → Rename - Right-click sheet tab → Delete - Drag sheet tabs to reorder

Logical Functions (IF, AND, OR, NOT)

Logical functions allow you to make decisions and perform different calculations based on conditions.

IF Function

Syntax: =IF(logical_test, value_if_true, value_if_false) Examples: =IF(A1 > 100, "High", "Low") =IF(B2 = "Yes", 0.1, 0) =IF(C3 >= 90, "A", IF(C3 >= 80, "B", "C"))

AND, OR, NOT Functions

LOGICAL FUNCTION COMBINATIONS
AND function (all conditions must be true): =AND(A1 > 0, B1 < 100, C1 = "Yes") OR function (at least one condition must be true): =OR(A1 = "Red", A1 = "Blue", A1 = "Green") NOT function (reverses the logic): =NOT(A1 = "No") Combined with IF: =IF(AND(A1 >= 90, B1 >= 90), "Excellent", "Needs Improvement") =IF(OR(C1 = "Manager", D1 > 50000), "Senior", "Junior")

IFERROR Function

Handles errors gracefully: =IFERROR(A1/B1, "Division by zero") =IFERROR(VLOOKUP(A1, B:C, 2, FALSE), "Not found")

Lookup Functions (VLOOKUP, HLOOKUP, XLOOKUP)

Lookup functions allow you to find and retrieve data from a table or range based on specific criteria.

VLOOKUP Function

Syntax: =VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup]) Parameters: - lookup_value: What to search for - table_array: Where to search (include headers) - col_index_num: Which column to return (1-based) - range_lookup: TRUE (approximate) or FALSE (exact) Example: =VLOOKUP(A2, $D$2:$G$100, 3, FALSE)

HLOOKUP Function

Similar to VLOOKUP but searches horizontally: =HLOOKUP(lookup_value, table_array, row_index_num, [range_lookup]) Example: =HLOOKUP(A2, $A$1:$Z$5, 3, FALSE)

XLOOKUP Function (Excel 365/2021)

Modern replacement for VLOOKUP: =XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode], [search_mode]) Advantages: - Searches in any direction - Returns arrays - Has built-in error handling - More flexible matching options Example: =XLOOKUP(A2, D:D, E:E, "Not found")

Conditional Formatting

Conditional formatting automatically applies formatting to cells based on their values or formulas.

Basic Conditional Formatting Rules

CONDITIONAL FORMATTING TYPES
Highlight Cell Rules: - Greater Than / Less Than - Between values - Equal To - Text Contains - Date occurring Top/Bottom Rules: - Top 10 items - Top 10% - Above/Below Average - Above/Bottom 10% Data Bars: Horizontal bars in cells Color Scales: Gradient colors Icon Sets: Arrows, flags, symbols

Custom Formula-Based Formatting

Use formulas for complex conditions: Highlight duplicates: =COUNTIF($A:$A, $A1) > 1 Highlight weekends: =WEEKDAY(A1, 2) > 5 Highlight based on another cell: =$B1 > $C1 Conditional formatting with dates: =TODAY() - A1 > 30 (over 30 days old)

Managing Conditional Formatting

  • Home → Conditional Formatting → Manage Rules
  • Rules are evaluated in order (first match wins)
  • Can copy formatting with Format Painter
  • Clear rules from selected cells or entire sheet

PivotTables - Basics

PivotTables are powerful tools for summarizing, analyzing, and presenting large amounts of data.

What is a PivotTable?

  • Interactive way to summarize large datasets
  • Can rearrange data dynamically
  • Automatically calculates subtotals and totals
  • Easy to create charts from PivotTable data
  • Can handle thousands of rows of data efficiently

Creating a PivotTable

Step-by-step process: 1. Select your data range (or table) 2. Insert → PivotTable 3. Choose where to place the PivotTable 4. Drag fields to areas: - Rows: Categories to display as rows - Columns: Categories for column headers - Values: Fields to summarize (Sum, Count, Average, etc.) - Filters: Fields to filter the entire PivotTable

PivotTable Areas

AreaPurposeExample
RowsCategories for row labelsProduct names, months
ColumnsCategories for column headersRegions, years
ValuesData to summarizeSales amounts, quantities
FiltersFilter entire tableDate ranges, categories

Value Field Settings

SUMMARY FUNCTIONS
Sum: Total of values Count: Number of entries Average: Mean of values Max: Highest value Min: Lowest value Product: Multiply values Count Numbers: Count numeric entries StdDev: Standard deviation Var: Variance

Excel Dashboards & Reporting

Dashboard Design Principles

  • Simple Layout: Avoid clutter, use white space effectively
  • Consistent Design: Same colors, fonts, and styles throughout
  • Interactive Elements: Slicers, drop-downs for filtering
  • Key Metrics First: Most important KPIs at the top
  • Mobile-Friendly: Consider how it looks on different screens

Building a Simple Dashboard

Charts Section: - Mix of chart types (bar, line, pie) - Consistent color scheme - Clear titles and labels 4. Interactive Filters: - Slicers for easy filtering - Drop-down menus - Timeline controls 5. Details Section: - PivotTables for drill-down - Raw data tables (filtered)

Array Formulas and Dynamic Arrays

Array formulas and dynamic arrays (Excel 365/2021) allow you to perform complex calculations and return multiple results.

Traditional Array Formulas

Enter with Ctrl + Shift + Enter (CSE): Single cell array formula: {=SUM(A1:A10*B1:B10)} Multi-cell array formula: Select B1:B10, enter =A1:A10*2, press Ctrl+Shift+Enter Common uses: - Sum products: {=SUM(A1:A10*B1:B10)} - Count unique: {=SUM(1/COUNTIF(A1:A100,A1:A100))} - Extract unique values: Complex INDEX/MATCH combinations

Dynamic Arrays (Excel 365+)

DYNAMIC ARRAY FUNCTIONS
FILTER function: =FILTER(A2:A100, B2:B100="Active") SORT function: =SORT(A2:A100, 1, TRUE) - ascending =SORT(A2:A100, 1, FALSE) - descending UNIQUE function: =UNIQUE(A2:A100) - remove duplicates SEQUENCE function: =SEQUENCE(10) - numbers 1-10 =SEQUENCE(5,3,10,2) - 5x3 array starting at 10, step 2 SORTBY function: =SORTBY(A2:A100, B2:B100, 1) - sort A by B ascending

Advanced Dynamic Array Techniques

Spilling ranges: - Formulas that return multiple values automatically "spill" - Referenced with # symbol: =SORT(A1#) Combining functions: =FILTER(SORT(A2:A100), B2:B100>100) Dynamic named ranges: - No need for OFFSET formulas anymore - Ranges automatically expand/contract

Data Tables

COMMON DAX FUNCTIONS

Introduction to Macros and VBA

Macros automate repetitive tasks in Excel using VBA (Visual Basic for Applications).

What are Macros?

  • Recorded sequences of actions
  • Written in VBA programming language
  • Can be triggered by buttons, shortcuts, or events
  • Save time on repetitive tasks
  • Reduce human error
  • Can include logic and decision-making

Recording a Macro

Step-by-step recording: 1. View → Macros → Record Macro 2. Name your macro (no spaces, start with letter) 3. Assign shortcut key (optional) 4. Choose storage location (This Workbook) 5. Perform the actions you want to record 6. View → Macros → Stop Recording Recording tips: - Plan your steps before recording - Avoid selecting cells unnecessarily - Use relative references when needed - Test the macro after recording

Running Macros

MACRO EXECUTION METHODS
Method 1: Keyboard shortcut - Press the assigned shortcut key Method 2: Macro dialog - View → Macros → View Macros - Select macro and click Run Method 3: Button on worksheet - Insert → Shapes → Rectangle - Right-click → Assign Macro Method 4: Quick Access Toolbar - File → Options → Quick Access Toolbar - Add "Run Macro" command Method 5: Ribbon button - Customize Ribbon → Add New Group - Add macro commands

Macro Security

Excel Macro Security Levels: - Disable all macros without notification - Disable all macros with notification - Disable all macros except digitally signed - Enable all macros (not recommended) Best practices: - Only enable macros from trusted sources - Use digital signatures for important macros - Keep macro-enabled workbooks (.xlsm) separate - Regularly scan for viruses
